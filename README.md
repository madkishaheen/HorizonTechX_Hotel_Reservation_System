# 🏨 Hotel Reservation System

A simple Java-based Hotel Reservation System that allows users to manage hotel rooms and reservations.

## 📌 Project Overview

The Hotel Reservation System is a console-based Java application designed to manage hotel room information and customer reservations.

The project demonstrates basic Java programming concepts such as:

- Classes and Objects
- Encapsulation
- Constructors
- Methods
- ArrayList
- User Input
- Conditional Statements
- Loops
- Object-Oriented Programming (OOP)

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- Java Collections
- VS Code / IntelliJ IDEA / Eclipse

## ✨ Features

- Manage hotel rooms
- Check room availability
- Make hotel reservations
- View reservation details
- Manage customer and room information
- Simple and easy-to-use console interface
- Demonstrates Object-Oriented Programming concepts
- Uses Java classes, objects, methods, and collections

##Open the Project

Open the HotelReservationSystem folder in VS Code or any Java IDE.

## Compile the Program

Open the terminal inside the project folder and run:
